# MacGameDeck artwork

The selected **Arcade Yellow** icon combines an executable document, controller and lightning bolt. It represents launching Windows games on macOS; the app does not convert executables into native Mac applications.

- Master: [AppIcon.png](AppIcon.png)
- Shipping resource: [AppIcon.icns](../Sources/MacGameDock/Resources/AppIcon.icns)
- Saved alternatives: [vermilion](Concepts/vermilion.png), [blue cartridge](Concepts/cartridge-blue.png), [yellow original](Concepts/arcade-yellow.png)

Generated with the built-in imagegen tool. ICNS contains 16–1024 pixel representations, including Retina sizes. Xcode and `scripts/build-app.sh` copy it into `Contents/Resources` and set `CFBundleIconFile`.

## Selected prompt

One macOS app icon in bold flat retro graphic design for a Windows-game launcher. A warm ivory document with a folded corner, tilted slightly counterclockwise, shaped into a compact game controller. Black D-pad, two round buttons, ".exe" lettering and a central lightning bolt. Golden yellow rounded-square background, ivory and near-black inks, hard offset shadow, strong silhouette and generous margins. No glow, glossy plastic, brand logos or mockup. Transparent outside the tile.
