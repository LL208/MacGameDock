# Steam API bridge

GSE regular Windows x86/x64 binaries from the upstream release `release-2026_09_27`, original GPL license in app resources, pinned source archive supplied beside this README. Upstream source and build instructions: https://github.com/Detanup01/gbe_fork/tree/release-2026_09_27

Original game DLLs and steam_settings are backed up before replacing them. No official Steam client is installed. Account/app IDs come from the authenticated account. DLC unlock_all is disabled; no SteamStub unpacker or DRM patch is included. Native macOS games do not use these Windows binaries.
